# Included typefaces

Downloaded without modification from the official Google Fonts repository:

- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond): upright and italic variable fonts.
- [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans): upright and italic variable fonts.

Each directory includes its original `OFL.txt`. Install the `.ttf` files for editable layout work. The reading HTML already embeds them.
